# 第二章 给猫准备一个家

很多新手接猫前，看着网上的“养猫必买清单”，往往忍不住把购物车塞满。但其实，猫咪对物质的需求极其简单。这一章我们不谈花钱，只谈如何用最基础的物品，站在猫的视角，为它打造一个安全、有安全感的“新地盘”。

## 2.1 必需品和可以晚点买的东西

在接猫回家之前，你只需要准备好下面这五样**核心必需品**，其他的统统可以等猫到家后，看它的习惯再慢慢添置。

### 🛒 接猫前的“五大件”
1. **猫砂盆**
   * **用途**：解决生理需求。
   * **怎么选**：**越大越好**。最好选无盖、敞开式的（通风好、猫有安全感），长度至少是猫身长的1.5倍。千万别一上来就买昂贵的全自动猫砂盆，故障或噪音可能会吓到刚换环境的猫。
2. **食盆和水碗**
   * **用途**：吃喝。
   * **怎么选**：材质选陶瓷或不锈钢（不易黑下巴、好清洗）。**重点：水碗和食盆要分开摆放**，不要挨着，猫在野外不喜欢在水源旁边进食。
3. **航空箱**
   * **用途**：接猫回家、日常去医院。
   * **怎么选**：选硬壳、顶部能打开的航空箱。不要买那种软塌塌的宠物包，猫咪在里面没有支撑感，会极度恐慌。
4. **猫抓板**
   * **用途**：磨爪子（这是猫的天性），顺便拯救你的沙发。
   * **怎么选**：买最基础的瓦楞纸平板抓板或碗型抓板即可。可以多买两块，家里各处放一块。
5. **休息处（猫窝）**
   * **用途**：睡觉。
   * **怎么选**：**别买太贵的**。因为不管你买多豪华的猫窝，它最后可能更喜欢快递纸箱。准备一个简单的半封闭猫窝，或者直接拿个干净纸箱垫上旧衣服就行。

> **完全可以晚点买的**：各种花里胡哨的玩具（逗猫棒可以先买一根）、营养膏、化毛膏、自动饮水机、复杂的猫爬架。等它熟悉环境后，根据它的喜好再买。

## 2.2 从猫的角度布置房间

猫是领地意识极强的动物。刚到新家的猫，第一反应往往是害怕和躲藏。布置房间的终极原则是：**让猫觉得“一切都在我的掌控之中”。**

### 🗺️ 划分四大功能区
1. **躲藏区（安全感来源）**
   * 刚到家的前三天，猫大概率会躲起来。请在安静的角落（如床底、沙发下、或者一个空纸箱）给它留出隐蔽空间。**不要硬把它拽出来**，让它知道“这里有个安全的避风港”比什么都重要。
2. **高处（巡视领地）**
   * 猫喜欢俯视。如果家里有柜子顶、置物架，确保它们平稳且能跳上去。高处能给猫极大的自信心和安全感，如果家里没有高处，可以等熟悉后添置一个猫爬架。
3. **进食区（安静且独立）**
   * 放在安静的角落，避开人来人往的走廊。如前所述，食盆和水碗分开一点距离，远离猫砂盆。
4. **如厕区（远离进食区）**
   * 猫砂盆必须放在通风、安静的地方，**绝对不能和食盆放在一起**。猫非常爱干净，不会在吃饭的地方上厕所。如果家里是复式或多层，建议每层放一个猫砂盆。

## 2.3 接猫前的安全检查（逐项检查表）

小猫的好奇心能要了它的命。在接猫前，请拿着这张表，花一个小时把家里彻底排查一遍：

### 📋 接猫前家庭安全自查清单

- [ ] **门窗与阳台**
  * [ ] 所有对外的窗户都已安装**牢固的金属防护网**（塑料网不行，猫能咬破）。
  * [ ] 阳台完全封闭（推拉门平时必须关好）。
  * [ ] 纱窗检查：是否有破洞？是否容易被猫挠开？（建议换成金刚网）。
- [ ] **线缆与电器**
  * [ ] 暴露在外的充电线、插线板用理线器收好，或藏在走线槽里（猫极易咬电线导致触电）。
  * [ ] 洗衣机、烘干机用完随时关门（防猫钻入）。
- [ ] **危险物品（务必收进带盖的柜子或高处的抽屉）**
  * [ ] **药品**：人吃的感冒药、退烧药（特别是含对乙酰氨基酚的成分，对猫剧毒）。
  * [ ] **清洁剂**：84消毒液、洗衣液、洗洁精（很多含氯或酚类成分对猫有毒）。
  * [ ] **小物件**：针线、橡皮筋、塑料袋、牙线、电池（防误食导致肠梗阻）。
- [ ] **植物排查（常见剧毒植物）**
  * [ ] 家里是否有百合、绿萝、龟背竹、滴水观音、郁金香、芦荟？（如有，立刻移出或送人）。

**本章小结**：
布置新家不需要花很多钱，但需要花很多心思。当你能用猫的视角去审视你的房间，做好了每一次安全隐患的防范，你就已经是一个合格的新手家长了。
