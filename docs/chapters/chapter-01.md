# 第一章 

养猫之前，先想清楚

## 第一节
养猫是一件浪漫的事，但也是一件极其现实的事。很多冲动养猫的人，最后往往是人猫两伤。在把那个毛茸茸的小生命带回家之前，我们需要先放下滤镜，算算账、看看屋子，也问问自己：我真的准备好了吗？

1.1 我适合养猫吗？
决定养猫之前，先别问“我喜不喜欢猫”，而是问自己四个现实问题：

时间：你每天能分出多少注意力？
猫虽然比狗独立，但绝不是给口饭吃就行。每天铲屎、换水、喂食、梳毛是基础。更重要的是，你需要每天抽出至少 15-30 分钟陪它玩耍，消耗它的精力。如果你每天加班到深夜、回家倒头就睡，或者频繁出差，那猫咪可能会因为缺乏陪伴而抑郁、拆家。

预算：除了猫粮，你算过“隐形开销”吗？
养猫不是一次性消费。每月的固定开销（好猫粮、猫砂、驱虫）是基础；更重要的是医疗准备金。猫咪生病（比如肠胃炎、尿闭）去一次医院动辄几百上千。建议你在养猫前，每个月能稳定存下一笔“猫咪医疗基金”，或者有底气随时拿出几千块应急。

居住条件：你的屋子安全吗？封窗了吗？
不管租房还是买房，封窗是底线！猫咪没有“跳楼”的概念，飞虫和小鸟的诱惑会让它们不顾一切冲出去。此外，你的室友或房东同意吗？如果租房，最好提前确认合同里是否允许养宠物，免得日后被迫送养。

出差或节假日：谁来照顾它？
猫不能跟着你到处跑。出差、长假回老家时，你是找上门喂养、送去寄养，还是拜托靠谱的朋友？提前想好这个退路，能避免很多麻烦。

核心自测：如果以上任何一条让你觉得“有点勉强”，建议先缓一缓。等条件成熟了，再迎接猫咪也不迟。

1.2 幼猫、成年猫，怎么选择？
很多人偏爱从小养起，觉得“从小养更亲人”。但幼猫和成年猫，其实对应着完全不同的生活节奏。

幼猫（0-6个月）：像养了个人类婴儿

优点：从小看着长大，感情基础深厚；能自己塑造它的生活习惯。

缺点：精力极其旺盛，半夜跑酷、咬手咬脚是常态；肠胃脆弱，容易软便；需要打全疫苗，期间不能出门。你需要大量的耐心去教导它（比如用猫抓板代替沙发）。

成年猫（1岁以上）：省心，但需要磨合

优点：性格已经定型，是粘人还是高冷，你一眼就能看出来；身体素质和免疫力相对稳定，作息更容易跟你同步。

缺点：如果之前有过不好的经历，可能需要花几个月甚至更久来建立信任；有些坏习惯（比如护食）纠正起来比幼猫难。

选择建议：如果你是上班族、新手、或者耐心有限，强烈建议考虑性格温顺的成年猫；如果你有充足的时间和精力，并且享受陪伴一个小生命成长的过程，幼猫会给你很多惊喜。

1.3 从哪里迎接一只猫？
“去哪里买猫”是新手最容易踩坑的地方。为了减少后院猫舍的悲剧，强烈建议优先考虑领养。

领养渠道：当地的动物救助站、流浪动物领养日、靠谱的宠物医院，或者个人家庭因为特殊原因无奈送养的。

与原照顾者沟通，必须问清这几个问题：

它现在的饮食（吃什么猫粮、罐头）、排便习惯。
有没有既往病史？疫苗打了几针？驱虫做了没有？
性格怎么样？怕生吗？喜欢被抱吗？
有没有绝育？如果没有，为什么？
交接事项：要求对方提供疫苗本、体检报告或病历。如果是送养人，最好能拿到它以前用的猫砂盆、旧毯子或玩具，这些带有它熟悉气味的物品，能极大地缓解它到新家的应激反应。

避坑提醒：尽量避开那些“不让上门看猫”“急着让你交定金”的私人卖家。真正爱猫的送养人，往往比你还要挑剔，因为他们希望猫咪能去一个安稳的家。
