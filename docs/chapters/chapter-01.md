# 《和猫一起生活》初版目录

| 章节 | 小节 | 这一节可以写什么 |
|---|---|---|
| **第一章：养猫之前，先想清楚** | 1.1 我适合养猫吗？ | 时间、预算、居住条件、家人意见，以及出差时谁来照顾。 |
|  | 1.2 幼猫、成年猫，怎么选择？ | 不同年龄的照顾需求、生活节奏，以及选择时要了解的信息。 |
|  | 1.3 从哪里迎接一只猫？ | 领养流程、与原照顾者沟通的问题、已有健康记录和交接事项。 |
| **第二章：给猫准备一个家** | 2.1 必需品和可以晚点买的东西 | 猫砂盆、食水容器、航空箱、抓板、休息处；说明用途，避免写成购物广告。 |
|  | 2.2 从猫的角度布置房间 | 躲藏处、高处、休息区、进食区和如厕区怎样安排。 |
|  | 2.3 接猫前的安全检查 | 门窗、阳台、线缆、药品、清洁剂和植物；做成逐项检查表。 |
| **第三章：一起度过最初的日子** | 3.1 接猫回家的当天 | 出发前准备、运输、到家后的安置，以及交接资料整理。 |
|  | 3.2 它为什么躲着我？ | 用具体场景介绍适应过程、需要观察的行为，以及如何建立信任。 |
|  | 3.3 怎样知道它适应得如何？ | 记录进食、饮水、排泄、活动和互动变化；避免给所有猫规定同一时间表。 |
| **第四章：吃饭这件大事** | 4.1 看懂猫粮包装 | 食品类型、适用生命阶段、营养完整性、配料表和喂食说明。 |
|  | 4.2 建立合适的喂食安排 | 怎样结合年龄、体况和食物热量制定计划；记录实际摄入，说明何时咨询兽医。 |
|  | 4.3 换粮、零食和饮水 | 换粮时需要关注什么，零食如何计入饮食，以及怎样观察饮水习惯。 |
| **第五章：日常照顾不只是铲屎** | 5.1 猫砂盆怎么选、怎么放？ | 尺寸、位置、猫砂选择和清理；配一张家中摆放示意图。 |
|  | 5.2 梳毛、剪指甲和口腔照顾 | 每件事的准备、循序渐进的练习、猫咪反馈和停止条件。 |
|  | 5.3 一份实际可用的照顾清单 | 按每天、每周和定期任务整理，再根据自己的猫调整。 |
| **第六章：学会听懂猫的表达** | 6.1 尾巴、耳朵和身体在说什么？ | 用照片或连续动作解释，强调结合情境观察，不凭一个动作下结论。 |
|  | 6.2 怎么玩，猫才愿意参与？ | 不同游戏方式、玩具选择、互动过程，以及你观察到的偏好。 |
|  | 6.3 抓家具、咬手和半夜叫怎么办？ | 每种问题单独写：发生场景、可能影响因素、观察方法、环境调整和求助渠道。 |
| **第七章：健康管理与就医** | 7.1 建立一份健康档案 | 体重记录、既往疾病、检查结果、疫苗和寄生虫管理记录。 |
|  | 7.2 怎样让看兽医更顺利？ | 航空箱适应、预约前准备、带什么资料，以及怎样描述问题。 |
|  | 7.3 出现异常时，先做什么？ | 怎样记录症状、联系医院、准备运输；急症识别内容由兽医资料支撑。 |
| **第八章：生活变化时，也照顾好它** | 8.1 新猫加入家庭 | 接猫前准备、分阶段接触、观察关系变化和调整节奏。 |
|  | 8.2 搬家、旅行和寄养 | 每种情境分别列出准备清单、交接信息和回来后的观察。 |
|  | 8.3 从幼年到老年 | 不同生命阶段的照顾重点，以及生活环境、饮食和健康管理怎样重新评估。 |
| **第九章：我们一起生活的故事** | 9.1 我曾经做错的事 | 具体写发生了什么、当时为什么这样做、后来怎样改变。 |
|  | 9.2 我慢慢认识了这只猫 | 性格、习惯、偏好和变化，用日常小事写出它的独特之处。 |
|  | 9.3 属于我们的生活记录 | 照片、成长时间线、体重曲线和小故事，让这本书有你的声音。 |

附录可以放：接猫物品清单、日常记录表、就医资料清单，以及参考资料与更新日期。
