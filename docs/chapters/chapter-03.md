# 第三章 一起度过最初的日子

把猫接回家的前两周，决定了未来十几年你们之间的信任基础。很多新手在这个阶段最容易陷入自我怀疑：“它是不是不喜欢我？”、“我是不是做错了什么？”
请记住，猫咪不是不爱你，它只是需要时间确认：这里是不是一个安全的地方。

## 3.1 接猫回家的当天

### 🎒 出发前的准备
*   **航空箱**：里面垫上带有它原来气味的旧毯子或衣物（向原主人要的）。
*   **车内环境**：把航空箱放在车后座并固定好，盖上一条透气薄布（减少视野刺激，降低应激）。绝对不要抱着猫坐在副驾。
*   **原主人的交接**：当面核对疫苗本、病历记录，并询问最后一次喂食、排泄的时间。

### 🏠 到家后的“第一分钟”
1. **直接去安全屋**：不要把航空箱放在客厅让所有人围观。提着箱子，直接走进你已经提前布置好的安静房间。
2. **开门，然后走开**：把航空箱门打开，放在角落。**不要把它抱出来。** 让它自己决定什么时候出来。
3. **提供水和猫砂盆**：在它附近放好水碗和猫砂盆，然后离开房间，给它留出独处的空间。

### 📁 交接资料整理（建议建个备忘录）
在手机或电脑上建一个“猫咪档案”，当天记录下：
* 疫苗日期、驱虫日期。
* 正在吃的猫粮品牌、换粮比例。
* 原主人交代的注意事项（比如“它害怕吸尘器”）。

## 3.2 它为什么躲着我？

**躲藏，是猫在陌生环境中保护自己的本能。** 它不是讨厌你，它是害怕“未知”。

### 常见场景与应对指南

* **场景一：它钻进了床底/沙发底，死活不出来。**
  * **怎么办**：不要用扫把捅，不要大声叫喊。只要它不出来，你就在房间里放好水和食物，然后退出房间。等半夜家里安静了，它自然会出来吃喝。
* **场景二：你走过去，它就哈气或者躲开。**
  * **怎么办**：立刻停下脚步，不要直视它的眼睛（在猫界，直视是挑衅）。你可以缓慢眨眼，然后把头扭开。
* **场景三：它愿意出来了，但一有动静就炸毛。**
  * **怎么办**：保持日常动作的轻缓。不要在家里大扫除，不要用吸尘器，不要邀请朋友来家里聚会。

### 建立信任的三个“不”
1. **不强抱**：哪怕它再可爱，前三天也绝对不要强行抱它。
2. **不追着喂**：把食物放下就走，不要盯着它吃。
3. **不用手逗猫**：不要用手直接逗它玩（容易养成咬手的习惯），用逗猫棒。

## 3.3 怎样知道它适应得如何？

不要盯着“它有没有来蹭我”这个指标，这太苛刻了。真正的适应，体现在日常的生理和行为细节里。

### 📝 观察这四项指标（建议每天记下来）
1. **进食与饮水**：前两天吃得少是正常的，但如果连续 **48小时** 一口不吃、一口不喝，必须立刻联系原主人或兽医（猫绝食极易引发脂肪肝）。
2. **排泄情况**：去猫砂盆看看有没有尿团和便便。如果第一天没拉，可以先观察；但如果超过两三天不排泄，或者出现拉稀、尿血，马上联系医生。
3. **活动范围**：第一天只缩在一个角落，第二天开始偷偷巡视房间，第三天敢跳上窗台——这就是巨大的进步。
4. **互动变化**：从哈气 → 到不再躲你 → 到你坐在旁边它敢继续吃饭 → 到愿意闻你的手 → 再到主动蹭你。这是一个渐进的过程。

### ⏳ 避免同一时间表
*   **胆小的猫**：可能需要 1-2 周才敢出房间门，这都是正常的。
*   **胆大的猫**：可能当晚就巡山了。
*   **亲人的猫**：第二天就来蹭你。
*   **敏感独立的猫**：可能一个月后才会主动来你腿上趴着。

> **新手心法**：不要拿网上的“神仙猫咪”跟自家猫比。只要它每天有一点点微小的进步，哪怕只是往前迈了半步，都值得你欣慰。慢一点，没关系的。
